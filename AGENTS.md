# Working on Undercut

Read docs/plan.md and docs/architecture.md before changing behavior. Keep implementation, tests, and docs aligned. Use Node 24 and pnpm with the committed lockfile. For preview and production, CI builds and starts the release containers, checks the live/ready/version endpoints, and runs one minimal shop startup/render smoke check on each supported browser/device platform via `pnpm test:browser:smoke`. Keep automated tests limited to this platform smoke check unless the user explicitly requests additional tests. Do not add visual geometry, screenshot/pixel comparison, gameplay/auth interaction, source, domain, or API test assertions unless explicitly requested. Keep setup needed to launch the app minimal. Production publishing still verifies signed image provenance and deployed health.

Game rules belong in packages/game-core; the server is authoritative. Preserve campaign ownership, atomic commands, idempotency, and forward-compatible saves. Never place credentials, invitation links, real account data, or runtime volumes in Git. Do not reset production. Database migrations must remain compatible with the previous application release. Public visibility does not imply an open-source license.

The long-term game uses trade to influence nations across independent branching campaigns. The first milestone is shop mechanics only. Do not add story, national simulation, multiplayer, offline writes, or cross-run bonuses without an agreed scope change.
