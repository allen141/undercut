# Traveler sprite sheets

These transparent 3×2 sprite sheets were supplied in `traveler_2d_animated_sprites.zip` (version 1.0.0). Each frame is 512×512 pixels and the character faces right in a profile/three-quarter view.

The dev-only WebGL shop uses:

- `idle_read_map_sheet.png`: six frames at 4.167 fps while waiting and trading.
- `walk_read_map_sheet.png`: six frames at 6.25 fps during the approach.
- `walk_sheet.png`: six frames at 6.667 fps while leaving.

Keep the full transparent frame canvas; all frames share the same bottom-center origin.
